Stimulus (STIMULUS)

STIMULUS TITLE: Stimulus 1 INSTRUCTIONS: Read the passage and answer the questions that follow. Q: Paste your full passage here — even a long one. You can leave blank lines between paragraphs exactly as you'd paste from a Word document. They won't be mistaken for the start of a new question. Each paragraph gets its own line break when shown to students. MC | 1pt Q: A question about the stimulus. *A: Correct A: Wrong ESSAY | 2pt Q: Another question about the same stimulus.

Every gradable question after a STIMULUS block automatically attaches to it — until the next STIMULUS appears, or an explicit ENDSTIMULUS line, or the end of the quiz. A plain TEXT block in between does not break or extend a grouping — it's just unrelated filler. INSTRUCTIONS: is shown to students alongside the passage (optional). Paste multi-paragraph text straight in — blank lines between paragraphs are preserved as paragraph breaks, not read as a new question; a new block only starts when an actual question-type line (like MC or ESSAY) appears on its own.

Multiple Choice (MC)

MC | 1pt TITLE: Question title (optional) Q: Question text here A: A. Wrong answer *A: B. Correct answer A: C. Wrong answer

Prefix correct answer with *. One correct answer only. TITLE: sets name in Canvas. The A: / *A: prefix is just parser syntax and is never shown to students — type A./B./C. into the answer text itself, as shown above, if you want visible labels.

True / False (use MC)

MC | 1pt TITLE: Question title (optional) Q: Tasmania is an island state of Australia. *A: True A: False

Create True/False as MC with True and False as the two options.

Multiple Answer (MA)

MA | 1pt TITLE: Question title (optional) Q: Select all that apply. *A: A. Correct option A: B. Wrong option *A: C. Also correct

Mark all correct answers with *. Partial credit awarded per correct answer. The A: / *A: prefix is just parser syntax and is never shown to students — to display A./B./C. labels on screen, type them as part of the answer text itself, like the example above.

Fill in the Blank (FITB)

FITB | 1pt TITLE: Question title (optional) Q: The capital of Tasmania is [city name]. *ANS: Hobart

One *ANS: line = exact match, single accepted answer.

FITB | 1pt Q: The capital of Tasmania is [city name]. *ANS: Hobart *ANS: hobart

Two or more *ANS: lines = "specify correct answers" — any of the listed strings is accepted.

FITB | 1pt Q: Ecology comes from the Greek root [word]. *ANS-CONTAINS: eco

-CONTAINS: correct if the student's answer contains this text anywhere.

FITB | 1pt Q: The capital of Tasmania is [city name]. *ANS-CLOSE: Hobart DISTANCE: 2 CASE: ignore

-CLOSE: tolerates typos (Levenshtein distance). DISTANCE: how many characters can differ (default 1). CASE: ignore makes it case-insensitive (default: case-sensitive, matching Canvas's own default).

FITB | 1pt Q: Choose the capital: [city name] *ANS-DROPDOWN: Hobart | Sydney | Melbourne

-DROPDOWN: first item is correct, rest are distractors shown in a dropdown menu.

FITB | 1pt Q: Choose the capital: [city name] WORDBANK: Hobart | Launceston | Devonport *ANS-WORDBANK: Hobart

WORDBANK: defines the full draggable word pool (correct + distractors) once. -WORDBANK: then just names which pool word is correct for this blank.

Multi-Blank (FITB-M)

FITB-M | 2pt TITLE: Question title (optional) Q: The capital is [city] (dropdown) and population is about [pop] (close enough). *BLANK1-DROPDOWN: Hobart | Launceston | Devonport *BLANK2-CLOSE: 250000 BLANK2-DISTANCE: 2 BLANK2-CASE: ignore

Each blank can use a different mode in the same question: plain *BLANKn: (exact — one line = single answer, multiple lines = specify correct answers), -CONTAINS, -CLOSE (+ BLANKn-DISTANCE:, BLANKn-CASE:), -DROPDOWN, or -WORDBANK. Points split evenly across blanks with partial credit.

FITB-M | 3pt Q: [one] plus [two] equals [three]. WORDBANK: 1 | 2 | 3 | distractor *BLANK1-WORDBANK: 1 *BLANK2-WORDBANK: 2 *BLANK3-WORDBANK: 3

All word-bank blanks in a question share one pool of draggable words (Canvas's real behaviour) — define it once with WORDBANK:, then each blank just names its correct word from that shared pool.

FITB-M | 1pt TITLE: True or False set Q: Decide if each statement is True or False. [blank1] The first statement goes here. [blank2] The second statement goes here. [blank3] The third statement goes here. *BLANK1: True *BLANK2: False *BLANK3: True

Write each statement on its own line, straight after the first Q: line — do NOT put "Q:" in front of every line, only the very first. Repeating "Q:" silently overwrites earlier lines and can make blanks fail to import with no error shown. Each line you write becomes its own line for students too.

Matching (MATCH)

MATCH | 4pt TITLE: Question title (optional) Q: Match each item to its description. PAIR: Term 1 | Description one PAIR: Term 2 | Description two PAIR: Term 3 | Description three

Each pair scores 1pt. Partial credit awarded.

Ordering (ORDER)

ORDER | 1pt TITLE: Question title (optional) Q: Put these steps in the correct order. LABEL-TOP: First LABEL-BOTTOM: Last *ITEM: Step 1 (correct position 1) *ITEM: Step 2 *ITEM: Step 3 *ITEM: Step 4 (correct position 4)

List *ITEM: lines in the correct order. LABEL-TOP/BOTTOM add anchor labels (optional). Canvas shuffles items for students.

Categorisation (CAT)

CAT | 1pt TITLE: Question title (optional) Q: Sort these items into the correct categories. CAT: Category 1 | Item A | Item B CAT: Category 2 | Item C | Item D

Each CAT: line = one category. Items after the first | belong to that category. Partial credit per category.

Essay (ESSAY)

ESSAY | 5pt TITLE: Question title (optional) Q: Discuss the impact of tourism on Tasmania. ... General feedback shown to all after submission. NOTES: Marking guide — instructor eyes only, never shown to students. RICHTEXT: no WORDCOUNT: yes WORDLIMIT: yes

... = student-visible feedback shown after submission. NOTES: = instructor-only marking notes, visible only in SpeedGrader — students never see this. RICHTEXT/WORDCOUNT/WORDLIMIT: yes/no (all default no). Word limit value set in Canvas after import.

File Upload (FILE)

FILE | 5pt TITLE: Question title (optional) Q: Upload your completed worksheet here.

Students see a file upload button. Requires manual grading.

Text Block (TEXT)

TEXT TITLE: title (use . if you want no title) Q: Read the passage below before answering...

No response, no points. Use for instructions, passages or section headers.

Rules

• Separate questions with a blank line
• Points: MC | 2pt on the type line
• TITLE: sets question name in Canvas (optional, all types)
• [label] in Q: places input box inline (FITB/FITB-M)
• FITB match modes: exact (default), -CONTAINS, -CLOSE, -DROPDOWN, -WORDBANK
• WORDBANK: line defines one shared word pool per question
• ... on ESSAY = general feedback after submission
• NOTES: on ESSAY = instructor-only marking notes (SpeedGrader only)
• STIMULUS block auto-attaches following questions until the next STIMULUS, an ENDSTIMULUS line, or end of quiz
• Use plain hyphens (-) not em dashes (–) in question text
• Lines starting with # are ignored (comments)
